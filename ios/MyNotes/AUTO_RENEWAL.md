# 这台 Mac 的 iPhone 手动续签

**当前使用手动脚本。** 用户已选择暂停自动任务；不会在后台自动续签或自动提醒。

## 双击使用

1. 保存手机上正在编辑的内容并返回主屏幕，保持 Mac 和 iPhone 解锁。
2. 两台设备连接同一 Wi-Fi，或用数据线连接。
3. 双击桌面 `My Notes iPhone 续签.command`。
4. 窗口会显示连接、版本核对、构建、安装及最终到期时间，完成后按回车关闭。

无需打开 Codex。入口源码位于 `scripts/MyNotes-iPhone-Renew.command`，桌面入口调用本机配置目录的脚本。手动入口使用 `--force --interactive`，因此无需等到仅剩 48 小时才可以续签。运行期间临时阻止 Mac 闲置睡眠，不改变屏幕锁定或其他永久设置。

**2026-10-29 更新：** 已从新版固定源码签名构建，通过数据线覆盖安装并启动 **0.1.4 (5)**；本版补充修复附件会话摘要留白，并保留同一 Hermes 回复重复气泡修复；源文件校验、11 项续签离线测试、桌面入口语法和脚本未到期检查均通过。历史曾出现 Xcode `No Accounts`，本轮签名构建未再遇到该错误。此次升级沿用已有有效描述文件，签名到期为 **2026-11-04 16:14（台北）**，没有强制申请新的 7 天周期；也没有重新测试无线续签整条流程。

本机配置目录为 `~/Library/Application Support/MyNotesRenewal/`，权限仅当前用户可访问。账号凭据仍由 Xcode / 系统钥匙串管理，脚本不保存 Apple 密码、验证码或私钥。

## 运行方式

- 当前 Codex 聊天的自动任务 `my-notes-iphone` 已暂停；手动脚本不依赖该任务。
- 不加参数执行底层脚本时，当前已安装签名剩余超过 48 小时则不构建、不连接手机、不安装。
- 手动双击入口直接尝试续签，通过已配对的 USB 或局域网连接安装。
- 当前固定快照为 `local-0.1.4-5-abb8ca892fd64197`，对应已测试并安装的 **0.1.4 (5)**，共 78 个文件。它是用户授权从已验证工作区生成的独立快照，并非新的 Git 提交；元数据保留基线提交、旧快照标识和清单 SHA-256。之后运行续签不会拉取远端或读取工作区变化。
- 备份并移走本应用的本地描述文件缓存，让 Xcode 自动申请更新；其他应用的描述文件、证书和手机数据均不处理。
- 验证团队、Bundle ID、设备、有效期、代码签名和安装返回结果。只有实际覆盖安装成功才更新“手机已安装版本的到期时间”。没有延长有效期的构建不算续签。
- 安装失败但签名成功时，下一次优先重试该安装包，避免反复申请描述文件。不会卸载应用、撤销证书、强制重启手机或自动启动应用。
- 手机上的版本与固定发布版本不一致时停止，避免把后续升级覆盖回旧版；已卸载的应用不会被任务重新安装。

## 无线与运行条件

这台 Mac 与 iPhone 已配对。iPhone 与 Mac 保持同一可互通的局域网时，CoreDevice 可通过 Bonjour 发现手机；不需要固定 IP。已在拔除数据线后观察到 `transportType=localNetwork` 并完成覆盖安装。

手动脚本需要 **Mac 开机、用户登录、钥匙串和 Xcode 账号可用**。手机不在网络中、处于暂时不可安装的锁定状态、Mac 钥匙串不可用或 Xcode 登录过期都会导致本次失败。请按窗口提示解锁设备或在 Xcode 重新登录，再手动重试；不应关闭系统安全保护来规避这些要求。

覆盖安装保留应用容器；正在运行的应用可能被系统终止。重要内容仍应保存或发送，内存草稿不属于持久保存的数据。首次验证时已请用户保存内容并返回主屏幕。

## 提醒与检查

手动运行时，结果直接显示在终端窗口。自动任务已暂停，不会另发后台提醒。底层 JSON 模式仍保留提醒去重字段，供今后明确恢复自动任务时使用。

本机状态及日志：

- `config.json`：团队、设备、固定版本、48 小时阈值。
- `source-manifest.json` / `source-metadata.json`：固定源码哈希及版本来源。
- `upgrade-backups/0.1.3-to-0.1.4-20261029T032133Z/`：本次升级前配置、状态、清单和旧构建；此前各版源码目录也继续保留。
- `state.json`：最近确认安装成功的签名到期时间。
- `status.json`：最近一次结果及是否需要提醒。
- `logs/`：最近一次构建、签名校验、设备检查、安装的诊断输出。
- `profile-backups/`：本应用描述文件缓存的恢复副本。

手动执行与自动任务相同的检查：

```sh
/opt/homebrew/bin/python3 "$HOME/Library/Application Support/MyNotesRenewal/renew.py"
```

`--force` 会在未到期时执行真实续签/覆盖安装，只用于明确需要的验证，不应添加到定时任务中。`--use-prebuilt` 用于首次验证已准备的签名包。两者仍须通过有效期延长和身份检查。

源码脚本：`scripts/renew-mynotes-ios.py`；离线行为测试：

```sh
python3 scripts/test-renew-mynotes-ios.py
```

“My Notes iPhone 自动续签”已暂停。保留本机配置不会影响已安装应用；签名仍将在描述文件标注时间到期。若未来需要恢复自动运行，应先修复 Xcode 账号并完成整条脚本的续签验证，再明确重新配置、核对调度；不要把历史计划频率当作现行任务状态。

免费签名仍有 7 天期限；此方案自动重复签名和安装，无法保证离开 Mac 超过 7 天仍可使用。
